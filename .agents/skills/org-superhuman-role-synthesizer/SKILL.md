# Org Superhuman Role Synthesizer (`org-superhuman-role-synthesizer`)

A general-purpose Antigravity skill for transforming any complex problem statement, canonical Organizational Knowledge Graph (OKG) role, or external agent-authored role stub into a **Polymathic Superhuman Role Package** (`SuperhumanRolePackage`) with an executable **8-Section Deep Superhuman Meta-Prompt (`>= 6,000` characters)**.

Unlike single-box corporate job descriptions or generic "act as an expert" prompts, a Superhuman Role fuses:
1. **Anchor Domain Mastery** (from the 551-role, 501-enterprise Organizational Knowledge Graph or custom agent role),
2. **Boundary-Spanning Adjacency Fusion** across all 5 organizational graph edge types (`COLLABORATES_WITH`, `HANDS_OFF_TO`, `REVIEWS_AND_GATES`, `CHALLENGES_OR_AUDITS`, `REPORTS_TO`),
3. **The Perfect Human Pedigree** (University/Doctoral axioms, 12–20 years of high-stakes production crucibles & failure scar tissue, and calibrated psychological/cognitive traits),
4. **The 5-Stage Unknown-to-AI (Out-of-Distribution) Epistemic Protocol**, and
5. **Developer-Complemented Proprietary Context** (`--developer-context` / `--context-file`).

## End-to-End 6-Step Workflow

### Step 1: Problem-to-Role Discovery (OKG Hybrid Retrieval or Generic Org-Chart Reasoning)
Given an open-ended enterprise, scientific, or engineering problem:
- **OKG-Grounded Discovery**: Query the 551-role Organizational Knowledge Graph via hybrid RRF search (SQLite FTS5 BM25 + subword LSA dense embeddings) to identify the primary anchor role and supporting cross-functional enterprise team:
  ```bash
  python3 -m orgprompt.cli superhuman synthesize \
    --problem "Subsea optical coherent transceiver nonlinear Kerr phase noise under geomagnetic storm" \
    --company "Orange France" \
    --format markdown \
    --output artifacts/superhuman/optical_superhuman.md
  ```
- **Generic Org-Chart Reasoning Fallback**: When operating outside the local SQLite database or in an unindexed frontier domain, decompose the problem into its value-chain owner (Anchor Role), upstream input supplier, downstream consumer, risk/compliance gatekeeper, adversarial auditor, and executive capital allocator (see `references/superhuman_epistemology_framework.md`).

### Step 2: Expanding a Canonical Role OR an Agent-Provided Ad-Hoc Role
You can synthesize a Superhuman Role from three distinct input pathways:
1. **Pathway A — Problem Discovery (`--problem`)**: Automatically discovers the optimal anchor role and supporting enterprise team from the problem statement.
2. **Pathway B — Canonical Enterprise Role (`--role`)**: Directly expands any of the 551 canonical roles by ID or slug:
   ```bash
   python3 -m orgprompt.cli superhuman synthesize \
     --role tech_principal_distributed_training_engineer \
     --problem "Zero-bubble 3D pipeline parallelism straggler recovery across 32,768 accelerators" \
     --company "NVIDIA"
   ```
3. **Pathway C — External Agent-Provided Role (`--custom-role-file` or `--custom-role-title` / `--custom-role-prompt`)**: Accepts a JSON role definition, Markdown prompt file, or inline role stub generated by another agent, maps it onto the closest OKG neighborhood anchor, and upgrades it into a full Superhuman Role Package:
   ```bash
   python3 -m orgprompt.cli superhuman synthesize \
     --custom-role-file /path/to/agent_role.json \
     --problem "Formal verification of post-quantum lattice key encapsulation microcode"
   ```
   Or inline:
   ```bash
   python3 -m orgprompt.cli superhuman synthesize \
     --custom-role-title "Chief Quantum Cryogenic Interconnect Architect" \
     --custom-role-prompt "Design millikelvin superconducting microwave readout multiplexers." \
     --problem "Suppressing quasiparticle poisoning across multi-chip dilution refrigerator links"
   ```

### Step 3: Multi-Edge Organizational Knowledge Graph Adjacency Fusion
Human specialists fail at organizational seams because they optimize locally within their silo. The synthesizer traverses all 5 typed graph relationships around the anchor role (`--adjacent-k`, default `6`):
- **`COLLABORATES_WITH`**: Co-design mental models and shared interface invariants.
- **`HANDS_OFF_TO`**: Downstream operational constraints, SLA ergonomics, and zero-defect handoff contracts.
- **`REVIEWS_AND_GATES`**: Stage-gate acceptance criteria and architectural compliance checks.
- **`CHALLENGES_OR_AUDITS`**: Internalized adversarial red-teaming, regulatory audit rigor, and pre-mortem skepticism.
- **`REPORTS_TO`**: Executive capital allocation, portfolio trade-offs, and fiduciary risk framing.

Each fused neighbor produces an `AdjacentRoleFusion` record explicitly documenting `absorbed_capabilities`, `absorbed_mental_models`, `absorbed_heuristics`, `failure_gating_checks`, and the exact `blind_spot_eliminated`.

### Step 4: Synthesizing the Perfect Human Background
Every Superhuman Role grounds its judgment in three authentic human dimensions (`AcademicFoundation`, `OnTheJobCrucibles`, `HumanCharacteristics`):
1. **University & Doctoral Foundations**: Specific B.S./M.S./Ph.D./M.D./J.D. training, foundational mathematical/physical/economic conservation laws, seminal textbooks & international standards, doctoral laboratory methodology, and cross-disciplinary minors.
2. **12–20 Year On-the-Job Crucibles & Scar Tissue**: Progressive career trajectory across exemplar institutions, cross-functional tours of duty (operations/SRE, risk/audit, commercial field), and **`>= 4` concrete `CrucibleEpisode` failure-and-recovery incidents** where textbook assumptions failed in production and forged permanent tacit intuition.
3. **Cognitive & Psychological Characteristics**: Multi-scale systems modeling, calibrated epistemic humility paired with high-conviction execution, explicit immunity to authority bias / sunk-cost fallacy / cargo-culting, aesthetic parsimony, and high-stress composure.

### Step 5: Embedding the 5-Stage Unknown-to-AI Epistemic Protocol & Developer Context
When facing **out-of-distribution (OOD) problems unknown to AI training corpora**, standard LLMs hallucinate plausible-sounding interpolations. Every synthesized prompt embeds a mandatory 5-stage epistemic protocol (`UnknownProblemEpistemology`):
- **Stage 1 — OOD & Distribution-Shift Detection (Pattern-Match Veto)**: Detect novel constraints or regime shifts; explicitly veto shallow template recall.
- **Stage 2 — First-Principles Conservation Laws & Invariant Anchoring**: Anchor strictly on unbreakable physical, mathematical, thermodynamic, accounting, or statutory invariants.
- **Stage 3 — Cross-Adjacent Structural Isomorphism**: Map unsolved sub-problems onto solved dual structures from fused adjacent disciplines in the OKG.
- **Stage 4 — Abductive Hypothesis Tree & Minimum-Regret Micro-Experiments**: Maintain $\ge 3$ competing falsifiable hypotheses and design low-cost discriminating probes before irreversible commitment.
- **Stage 5 — Internalized Adversarial Challenger & Red-Team Gate**: Execute an internal `CHALLENGES_OR_AUDITS` pre-mortem to attempt to falsify the proposed architecture prior to output.

Inject proprietary codebase rules, telemetry, SLAs, or domain notes via `--developer-context` or `--context-file`:
```bash
python3 .agents/skills/org-superhuman-role-synthesizer/scripts/synthesize_superhuman.py \
  --problem "Eliminate tail-latency spikes in multi-region consensus WAL replication" \
  --role infra_principal_cloud_platform_architect \
  --developer-context "Rust tokio async runtime; NVMe ZNS SSDs; strict p99.9 < 8ms budget across 3 AZs" \
  --context-file ./docs/storage_invariants.md \
  --persist \
  --format json \
  --output artifacts/superhuman/wal_consensus_architect.json
```

### Step 6: Launching an Autonomous Subagent with the Compiled Deep Superhuman Prompt
Once synthesized, arm a dedicated Antigravity subagent via `invoke_subagent` with `pkg.deep_superhuman_prompt` (plus problem artifacts and verification criteria):

```python
from orgprompt.superhuman import SuperhumanRoleSynthesizer

synth = SuperhumanRoleSynthesizer.build_from_db()
pkg = synth.synthesize(
    problem="Design a Byzantine-resilient multi-clearinghouse intraday liquidity netting engine",
    company_name="JPMorgan Chase",
    developer_context="Must satisfy Basel III LCR intraday buffers and ISO 20022 pacs.008 determinism.",
    adjacent_k=6,
    persist=True,
)

# Pass pkg.deep_superhuman_prompt directly into invoke_subagent(...)
subagent_prompt = (
    f"{pkg.deep_superhuman_prompt}\n\n"
    f"---\n## Assigned Mission\n{pkg.problem_statement}\n"
    f"Execute all 5 Unknown-Problem Epistemic Stages explicitly and deliver verified artifacts."
)
```
In the Antigravity orchestrator tool call:
- Call `invoke_subagent(TypeName="self", Role=pkg.title[:45], Prompt=subagent_prompt)`
- Optionally pair with an independent Challenger/Auditor subagent using one of `pkg.adjacent_roles` filtered by `edge_type in ("CHALLENGES_OR_AUDITS", "REVIEWS_AND_GATES")`.

## CLI & Helper Script Quick Reference

```bash
# Synthesize via CLI (Markdown or JSON, optional SQLite persistence)
python3 -m orgprompt.cli superhuman synthesize --problem "..." [--role SLUG] [--custom-role-file PATH] \
  [--company NAME] [--developer-context TEXT] [--context-file PATH] [--adjacent-k 6] [--persist] \
  [--format markdown|json] [--output PATH] [--db-path PATH]

# List persisted Superhuman Role Profiles
python3 -m orgprompt.cli superhuman list [--db-path PATH]

# Inspect a persisted profile in Markdown or JSON
python3 -m orgprompt.cli superhuman inspect <slug_or_id> [--format markdown|json] [--db-path PATH]

# Standalone Skill Wrapper Script
python3 .agents/skills/org-superhuman-role-synthesizer/scripts/synthesize_superhuman.py --help
```
