# Quickstart: Org Role Search & Scaffold

## Quick Commands Reference

| Action | CLI Command |
| :--- | :--- |
| **Hybrid Search** | `python3 -m orgprompt.cli search query "<query>" --top-k 10` |
| **Role Markdown Runbook** | `python3 -m orgprompt.cli scaffold role <role_slug> --format markdown --output <path>` |
| **Role JSON Specification** | `python3 -m orgprompt.cli scaffold role <role_slug> --format json --output <path>` |
| **Enterprise Scaffold** | `python3 -m orgprompt.cli scaffold company "<Company Name>" --format markdown --output <path>` |

## Typical Roles & Slugs
- `fin_chief_investment_officer` — Chief Investment Officer
- `fin_principal_fpga_trading_architect` — Principal FPGA Trading Architect
- `tech_principal_distributed_training_engineer` — Principal Distributed Training Engineer
- `telecom_chief_network_architect` — Chief Network Architect
- `health_chief_medical_officer` — Chief Medical Officer
- `aero_chief_engineer_starship` — Chief Engineer, Starship
